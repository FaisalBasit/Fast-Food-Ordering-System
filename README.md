# Fast Food Ordering System

A C# Windows Forms fast food ordering application created for the Burger Mania restaurant concept.

## Features

- Browse a restaurant menu
- Add and manage items in a cart
- Customer login and signup
- Capture delivery information
- Order confirmation and delivery details
- Payment workflow
- Customer reviews and feedback

## Technology

C# and Windows Forms.

## Use Case

The project demonstrates a desktop restaurant ordering system supporting menu browsing, cart management, customer accounts, ordering, and feedback.
